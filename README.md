# Pneumonia Detection Project

## Instructions to run

1. Create a folder called `dataset` and place the image dataset inside it, with the patient folders directly inside `dataset`.

2. Create a folder called `assignment1supportingfiles` and place the supporting files at these paths:
   - `assignment1supportingfiles/assignment1_labels.csv`
   - `assignment1supportingfiles/rsna_to_nih_mapping.csv`

3. Open the notebook and click **Run All Cells**.
